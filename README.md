# Hi, I build ManaWG

[**ManaWG**](https://github.com/Abuarchiv/manawg) is a free, open-source app for shared flats: expenses, cleaning rota, shopping list, calendar and chat, in one app you can self-host with Docker.

[Website](https://manawg.com/en) · [Open the app](https://app.manawg.com) · [Good first issues](https://github.com/Abuarchiv/manawg/labels/good%20first%20issue)

Related: [manawg-mcp](https://github.com/Abuarchiv/manawg-mcp), the MCP server that lets AI assistants help run a flat, and [manawg-landing](https://github.com/Abuarchiv/manawg-landing), the website.
